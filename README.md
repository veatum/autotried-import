# AutoTried — предварительная концепция

## GitHub Pages

Сайт: https://veatum.github.io/autotried-import/

Исходники находятся в ветке `main`, опубликованная статическая сборка в `gh-pages`.
Команда `npm run build:pages` собирает `dist-pages` для пути `/autotried-import/`.
При изменениях нужно повторно собрать и опубликовать содержимое `dist-pages` в `gh-pages`.
Эта версия работает без серверной части; исходная сборка Sites сохранена отдельно.

Лендинг по брифу клиента. Источники фактов: голосовое сообщение и предоставленное описание Telegram https://t.me/AutoTried_import. Контакт: https://t.me/autovibe_manager. Отзывы: https://t.me/auto_r (ссылка предоставлена заказчиком, содержание отдельно не проверено).

## Перед публичным запуском

- Получить оригинальный логотип, совместное фото команды и разрешение на публикацию. Сейчас используется временный текстовый знак, а не утверждённая эмблема.
- Согласовать название и написание AutoTried, юридические реквизиты, перечень услуг и текст страницы.
- Подтвердить доказательства и базу сравнения экономии 30–35%, условия сроков 3–4 недели. На странице это ориентиры из описания заказчика, а не гарантии.
- Подтвердить ссылку на отзывы, реальные кейсы и разрешения на материалы.
- Уточнить конкретные услуги по утильсбору, Кыргызстану и банковским платежам. Обход валютного контроля, неформальные наличные переводы и гарантии не рекламируются.
- Проверить юридические тексты для реального запуска. Форма не сохраняет запросы на сервер и не отправляет их автоматически. Посетитель сам открывает Telegram и отправляет сообщение; общая инфраструктура хостинга может вести технические логи.
- Удалить пометку концепции и разрешить индексацию только после согласования и выбора публичного размещения.

## Проверки

Сборка проекта, TypeScript и тесты генерации/валидации запроса. Мобильная доработка проверена в Chromium через Playwright на ширинах 320, 360, 375, 390, 414, 768 и 1280 px. Горизонтальное переполнение отсутствует. На 375×812 и 390×844 пройдены форма до черновика Telegram, возврат с сохранением данных, меню, FAQ, reduced motion и скрытие нижней панели при работе с формой. Ошибок JavaScript не выявлено. Скриншоты сохранены локально в output/playwright/mobile-fix, в репозиторий не включаются. На физических телефонах проверка не проводилась.

Опциональный WebMCP stage_import_inquiry готовит тот же видимый черновик, не отправляя сообщение. Его отдельная runtime-проверка в WebMCP-контексте не заявляется.
